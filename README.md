# docker-images
Production-ready Docker images for self-hosters: WordPress (OpenLiteSpeed, Nginx, LiteSpeed Enterprise), Ghost, Nextcloud, n8n, Open WebUI, Vaultwarden and more. Digest-pinned, hardened, proxy-ready. Maintained by RemarkableCloud.

The MIT license covers the contents of this repository: compose files, configuration and documentation. Each image contains third-party software that keeps its own upstream license (WordPress GPLv2, Nextcloud and Vaultwarden AGPLv3, Ghost MIT, and so on); a per-image "Upstream license" line in each README states it. Nothing here relicenses or endorses the upstream projects.
